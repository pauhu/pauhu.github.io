Features

  • Plain HTTPS

    Every route is in one OpenAPI contract. Any program, device or browser that speaks HTTPS can call it.

  • Results with sources

    Each result carries the sources it rests on, so your program can show them or check them.

  • A key for each device, coming

    Each device that calls Pauhu gets its own key, and you can withdraw a key at any time.

  • Devices and firewalls

    Outbound HTTPS to two host names, no inbound port. The firewall rules are open on GitHub.

  • On the device

    Reading text in a photo and reading text aloud run in the browser on the device, free; more is coming.

  • Also over MCP

    The same tools are reachable through MCP over streamable HTTP, with the same bearer key.

How it works

  1. Read the current offers and prices: GET https://api.pauhu.ai/v1/lds/outputs.
  2. Call a route from the OpenAPI contract over HTTPS. While payments are not open, an answer request returns HTTP 402.
  3. Use the result and its sources in your program. You approve each write and payment; nothing is charged without your approval.

No more copy-pasting and clicking. You choose which apps Pauhu may work in, and it asks before every write or payment. Working in your apps is coming; you can withdraw access at any time.
